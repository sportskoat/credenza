Android · Chrome · Edge

Install the app. That is the whole setup.

Credenza declares itself a share target. Once the app is installed, the system share sheet lists it next to Messages and Gmail. No shortcut to build.

  1. Open credenzafashion.com in Chrome.
  2. Open the browser menu and choose Install app (or Add to Home screen).
  3. Share any product page. Pick Credenza.

Share must go through the installed app, not the browser tab. If Credenza is not in the sheet, the install did not finish.

iPhone · iPad

Build the Shortcut once

iOS does not offer web apps to the share sheet. A two-action Shortcut does the same job. It takes about three minutes.

  1. Open Shortcuts. Tap +. Name it Stash in Credenza.
  2. Open the shortcut details (the i button). Turn on Show in Share Sheet. Set the accepted input to URLs and Text.
  3. Add the URL Encode action. Set its input to Shortcut Input.
  4. Add the Open URLs action. Set the URL to https://credenzafashion.com/?stash= and then insert the URL Encoded Text variable directly after the = sign.
  5. Save.

Do not skip the URL Encode step. A Weidian link carries its own ? and &. Pasted in raw, the browser reads everything after the first & as a separate parameter and Credenza receives half a link.

iPhone · step two

Pin it so it is one tap

A new Shortcut sits at the bottom of the share sheet, under everything else. Pin it once and it stays at the top.

  1. Share any web page.
  2. Scroll the sheet to the bottom. Tap Edit Actions.
  3. Tap the green + next to Stash in Credenza.
  4. Drag it to the top of Favorites. Tap Done.

Optional: open Credenza in Safari, tap Share, and choose Add to Home Screen. The app then opens full screen instead of in a browser tab.

Desktop

Drag one bookmark to the bar

On a laptop, a bookmarklet does the same thing from any product page. Make a new bookmark and put this in the URL field instead of an address:

javascript:location.href='https://credenzafashion.com/?stash='+encodeURIComponent(location.href)

Click it on a Weidian, Taobao, or Yupoo page. Credenza opens with the item stashed.

What arrives

Credenza reads three things

  • The link — classified as Weidian, Taobao, 1688, Yupoo, or a Reddit post.
  • The page title — used as the card title until you rename it.
  • Any selected text — kept with the card, so a pasted size chart is parsed later.

Share the same item twice and Credenza does not duplicate it. It opens the card you already have and tells you so.

Nothing here needs an account, and nothing is sent to a server to save the card. The shelf is local-first in your browser. Sharing to Credenza opens your own app on your own device.
