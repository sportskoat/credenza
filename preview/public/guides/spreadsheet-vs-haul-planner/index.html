Spreadsheet wins when

Simple lists and one buyer habit

  • You store only URLs and a price column.
  • You never attach QC photos to rows.
  • Size is “guess L” with no chart on the row.
  • One person, few items, rare reorders.
Planner wins when

Decisions need context

  • Yupoo photos and Weidian buy links must stay paired.
  • You match a seller chart to a body profile (in or cm).
  • QC → GL/RL status matters before you ship the parcel.
  • You open Superbuy or another agent without rewriting every stored URL.
Credenza

What the planner is (and is not)

Credenza is an agent haul planner: stash finds, size, track pipeline, open Buy in your agent. It is not a marketplace, not a search engine for sellers, and not a checkout.

Money model: free planner; optional agent affiliate only when you open Buy on a participating agent.

Migration

Leave the sheet without losing history

Paste links into Credenza as you decide. Keep the old sheet as archive if you want. You do not need a full import day-one—start with the active haul.

Credenza is a decision layer, not a marketplace and not a W2C search engine. You bring the links from communities and stores you already use.
