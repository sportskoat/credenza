Guides for agent haul planning

Clear answers to buying questions: organize links, size with confidence, open your agent. Not a product catalog.

Start with the step you are on: collect links, choose a size, check QC photos, plan the parcel, or open Buy with your agent.

If you are unsure where to start, check the size before you buy.

2 · Decide the size

This is the expensive stage. A size chart on a listing is measured flat, in centimetres, garment by garment: so the same label is a different garment across two stores. A wrong size is not a return; it is a second parcel and a second shipping fee. Do this before you buy, not after.
